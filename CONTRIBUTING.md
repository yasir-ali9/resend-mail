# Contributing

Contributions are welcome - bug fixes, new features, or any improvements.

## Getting started

```bash
git clone https://github.com/yasir-ali9/resend-mail
cd resend-mail
npm install
cp .env.example .env.local
npm run db:push
npm run dev
```

## Making changes

1. Fork the repository and create a branch.
2. Make your changes.
3. Run `npm run build` and test locally.
4. Open a pull request with a short description of what changed and why.

No contribution is too small.
